# 밸런스

여기 있는 값은 **바꿔도 공짜다.** 되돌릴 수 있고, LLM 재생성을 부르지 않는다.
그래서 코드가 아니라 데이터로 두었다 — 고치고 서버만 다시 띄우면 된다.

여기 **없는** 것들과 그 이유:

| | 어디에 | 왜 |
|---|---|---|
| 방 씨앗, NPC 페르소나·주제 | `server/engine/map.ts`, `npcs.ts` | 고치면 `seed_id` 가 바뀌어 **LLM 재생성 비용이 발생한다.** 리뷰를 거쳐야 한다 |
| 맵 구조(벽·출구), 적 배치 | `server/engine/map.ts` | 방이 생기거나 사라진다. 되돌리기 어렵다 |
| `sensitive_flags` 선언 | `server/engine/map.ts` | 하나 늘리면 그 방의 상태 수가 2배가 된다 (2^n 폭발) |
| 규칙 — 치명타 계산, 어그로, 큐 한 자리 | `server/engine/` | 데이터로 표현할 수 없다. 표현하려 들면 스크립트 언어가 된다 |

부팅 때 전부 검증한다 (`server/content/balance.ts` + `server/db/seed.ts`).
틀린 값이면 **서버가 뜨지 않는다** — 조용히 이상한 세계로 도는 것보다 낫다.

## 수치를 고칠 때는 돌려 보고 고친다

```
npm run sim               # 적마다 1대1 승률·소요 시간·남은 체력
npm run sim -- --runs 400
```

`server/tools/balanceSim.ts` 가 **실제 엔진 함수**(`resolvePlayerSwing` /
`resolveEnemySwing`)로 1대1을 돌린다. 데미지 공식을 다시 쓰지 않으므로
치명타·가드·스킬 쿨다운이 게임의 것과 같다.

`기본` 은 기본 공격만, `스킬` 은 체력이 낮으면 회복·아니면 강타를 쓰는 사람.
**포션은 계산에 없다** — 실제 승률은 표보다 높다.

`test/balance.ts` 가 불변식을 지킨다: 스킬을 쓰면 모든 적을 이길 수 있고,
보스는 기본 공격만으로는 이기기 어렵고, 스폰 지역에는 적이 없다.
수치를 잘못 고치면 플레이해 보기 전에 빨간불이 뜬다.

## `player.json` — 플레이어 기본치

| 필드 | | |
|---|---|---|
| `maxHp` | 최대 체력 | 새 캐릭터가 이 값으로 시작한다 |
| `swingMs` | 기본 공격 간격(ms) | 적보다 빠르게 두는 것이 기준이다 |
| `damage` | `[최소, 최대]` | 한 대당 |
| `critChance` | 0~1 | 치명타 확률. **기본 공격에만** 붙는다 (스킬은 이미 큰 숫자라 겹치면 스파이크가 과하다) |
| `critMult` | 배수 | |
| `respawnMs` | 쓰러진 뒤 일어나기까지(ms) | 회선이 끊겨 이 타이머를 잃어도 재접속하면 일어난다 |

**계산 예시** (지금 값): DPS ≈ `6 × 1.15 / 0.5초 ≈ 13.8/초`.

## `enemies.json` — 적의 '정의'

키가 곧 적 id 다. **어느 방에 있는지는 여기 없다** — 배치는 맵 구조이므로
`server/engine/map.ts` 의 `ENEMY_AT` 이 소유한다. 같은 적을 여러 방에 둘 수 있다.

| 필드 | |
|---|---|
| `maxHp`, `damage`, `swingMs` | 플레이어와 같은 의미 |
| `slainFlag` | 쓰러뜨리면 켜지는 월드 플래그. `null` 이면 세계를 바꾸지 않는다 |
| `respawnMs` | 돌아오기까지(ms). `null` 이면 영영 돌아오지 않는다 |
| `drops` | `{ itemId, qty, chance }` 목록. 피해를 준 사람 **전원**이 각자 판정을 받는다 |

**`slainFlag` 와 `respawnMs` 는 동시에 가질 수 없다** (부팅에서 막는다).
플래그를 켜는 적이 곧 '보스' 이고, 세계가 바뀐 사건은 되돌릴 수 없기 때문이다 —
파수꾼이 되살아나는데 `guardian_slain` 이 켜진 채 남으면 그 플래그를 선언한
방들의 묘사가 "파수꾼이 사라진 뒤" 인 채 파수꾼과 마주 보게 된다.

**혼자 잡을 수 있는가**를 이렇게 어림한다:
`maxHp / 13.8` 초가 걸리고, 그동안 `(damage 평균 / swingMs) × 그 시간` 만큼 맞는다.
플레이어가 40이므로 그 값이 40을 넘으면 치유 없이는 진다.

## `skills.json`

| `kind` | `power` 의 뜻 |
|---|---|
| `strike` | 피해 `[최소, 최대]` |
| `heal` | 회복 `[최소, 최대]`. 잃은 만큼까지만 |
| `guard` | 다음 피격 경감 **퍼센트**. 범위를 같은 값으로 두면 고정이다 |

스킬은 다음 스윙에 기본 공격을 **대신한다.** 큐는 한 자리이고 아이템과 나눠 쓴다.

## `items.json`

| `kind` | |
|---|---|
| `potion` | 쓰면 사라진다. `heal` 이 **반드시** 있어야 한다 |
| `trophy` | 쓸 수 없다. `heal` 은 `null` |

회복량이 범위가 아니라 **고정값**인 이유: 전투의 피해는 난수여야 리듬이 살지만
물약까지 흔들 이유가 없다. 고정이면 전투 밖에서 마실 때 난수원을 따로 만들 필요도
없고, 사람이 "이걸 마시면 얼마나 차는가" 를 셀 수 있다.
