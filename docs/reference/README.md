# 참고 자료

## `mudprototype.jsx`

1단계 이전의 단일 파일 React 프로토타입. **실행되지 않고, 빌드에 포함되지 않으며,
어디서도 import 되지 않는다.** 남겨 두는 이유는 두 가지다:

1. 목표하는 '느낌'의 기준 — JRPG 커맨드 윈도우, 미니맵, 로그의 색상표와 문장 톤.
   `client/theme.ts` 의 색상은 여기서 그대로 가져왔다.
2. 씨앗(`SEEDS`)과 민감 플래그(`SENSITIVE`)의 원본. 지금은 `server/engine/map.ts` 가 소유한다.

이 파일은 CLAUDE.md 의 절대 규칙을 **어긴다** — 클라이언트에서 직접 LLM을 호출하고
(규칙 2 위반), 생성 결과를 React state 에만 두어 플레이어마다 다른 세계를 만든다.
그것이 이 프로젝트가 서버 권위 재작성으로 시작한 이유다. 참고만 하고 베끼지 말 것.
