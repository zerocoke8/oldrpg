# prompt

이 구역을 지키던 그림자 파수꾼은 방금 쓰러졌다.
위협이 사라진 직후의 느슨한 정적을 담아라.
공기가 가벼워지고, 어둠이 덜 적대적으로 느껴진다.

# fallback

위협이 사라진 뒤의 느슨한 정적이 감돈다.

# label

파수꾼 처치됨

# near

주변의 공기가 달라졌다. 지나온 길이 예전 같지 않을 것이다.

# far

멀리서 무언가 무너지는 소리가 길게 이어지다 잦아든다.
