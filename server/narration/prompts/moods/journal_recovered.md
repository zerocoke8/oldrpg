# prompt

기록실의 괴령이 방금 흩어졌고, 연구 일지가 다시 사람의 손에 들어왔다.
없던 것으로 분류됐던 기록이 존재하기 시작한 직후의 공기를 담아라.
사라졌던 것들의 윤곽이 조금씩 돌아온다. 안심되는 변화는 아니다.

# fallback

없던 것으로 되어 있던 자리들이 다시 형체를 갖추기 시작한다.

읽히지 않던 표시들이 이제는 읽힌다.

여기 있었던 일이 여기 있었던 일로 남아 있다.

# npc_prompt

연구 일지가 다시 사람의 손에 들어왔다는 것을 이 사람은 이미 알고 있다.
그 사실이 말투에 배어 있되, 그것을 설명하지는 않는다.

# npc_fallback



# label

연구 일지 확보

# near

읽히지 않던 글자들이 한꺼번에 읽힌다. 여기 있었던 일이 여기 있었던 일이 된다.

# far

먼 곳에서 종이 넘기는 소리가 한 번, 아주 크게 들린다.
