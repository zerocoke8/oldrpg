# 지역의 톤 — `tones/<지역 id>.md`

`moods/<플래그>.md` 와 **같은 모양이고 같은 이유로 있는 것**이다.
플래그가 '언제' 라면 지역은 '어디' 다. 둘 다 씨앗에 붙는 프로즈다.

```
# prompt
LLM 에게 주는 그 지역의 톤 지시. 방 프롬프트의 {{tone}} 에 들어간다.

# room
폴백 꼬리 후보. 빈 줄로 구분한 각 줄이 후보이고 씨앗 해시로 고른다.
```

## 왜 만들었나

방 프롬프트 v1 의 system 절이 `어둡고 축축한 지하 던전 톤` 을 **164방 전부**에
걸고 있었다. 그런데 이 세계는 마을 40방 · 전진기지 30방 · 사무실 44방을 갖고
있다 — **114방(70%)이 던전이 아니다.** 씨앗이 "노점거리 한복판. 흥정 소리가
여러 언어로 섞인다" 라고 써 놓고 꼬리가 "목 안쪽이 서늘하다" 로 끝나면, 읽는
사람은 세계가 아니라 템플릿을 본다.

더 나빴던 것은 **모델이 사람보다 적게 알고 있었다**는 점이다. 렌더러에 가는
것은 씨앗 한 줄과 무드뿐이고 지역 이름조차 없었다. 그 상태로 키를 꽂으면
값이 나오는 게 아니라 각 방이 2~3문장으로 **더 길게** 어긋난다.

## 공짜인 변경이다

톤도 꼬리도 `state_hash` 의 preimage 에 들어가지 않는다 (`seed_id` 는 씨앗만,
`flags_decl_hash` 는 선언된 플래그만). 그래서 **톤을 고쳐도 `seed_id` 가 바뀌지
않는다** — 씨앗을 고치는 것과 완전히 다른 취급이다.

다만 이미 `source='fallback'` 으로 박힌 행은 옛 꼬리를 그대로 들고 있다.
톤을 새로 만들거나 크게 고쳤으면 폴백 행만 지우고 `npm run pregen` 을 다시
돌릴 것.

## 파일이 없어도 된다

톤 파일이 없는 지역은 `tails.ko.md` 의 전역 꼬리와 기본 톤으로 떨어진다.
그래서 검사의 픽스처 세계나 막 만든 지역이 톤 없이도 돈다 — 톤은 **덧칠**이지
필수 항목이 아니다.
